# Ping Pong Paddle Game

A classic Pong clone themed with ping pong paddles, built with Godot 4.5.1.

## Features

- **Two-player local multiplayer**
- **Ping pong paddle aesthetics** with colored paddles and handles
- **Classic Pong gameplay** with physics-based ball movement
- **Score tracking** - first to 10 points wins!
- **Dynamic ball speed** - increases slightly on each paddle hit
- **Angle-based bounces** - hit different parts of the paddle for different angles

## Controls

### Player 1 (Left - Blue Paddle)
- **W** - Move Up
- **S** - Move Down

### Player 2 (Right - Orange Paddle)
- **↑** (Up Arrow) - Move Up
- **↓** (Down Arrow) - Move Down

### General
- **ESC** - Reset the game

## How to Play

1. Open the project in Godot 4.5.1
2. Press F5 to run the game
3. First player to score 10 points wins!
4. The ball bounces off paddles and walls
5. Hit the ball with different parts of your paddle to control the angle

## Game Elements

- **Green Table Background** - Simulates a ping pong table
- **Blue & Orange Paddles** - Two-tone colored paddles with brown handles
- **White Ball** - Classic ping pong ball that speeds up during play
- **Dashed Center Line** - Divides the playing field
- **Score Display** - Shows each player's score at the top

## Technical Details

- Built with Godot 4.5.1
- Resolution: 1280x720 (resizable)
- Physics-based collision system
- Input mapping for two players
- Signal-based scoring system
